## 博客

**Claude Blog:Claude in Chrome 全面开放(GA)**

Claude in Chrome 现已对所有付费 Claude 套餐开放。最大的变化:Claude 现在可以在浏览器中**自主执行操作**,不再需要每个动作都请求批准——一个安全分类器会在每个动作执行前校验,确保安全且符合你的请求。它可以用你现有的登录态查看页面、读写文本、点击链接、跳转页面、填写表单,特别适合内部仪表盘、遗留系统、供应商门户这类没有现成连接器的场景。背后是 Anthropic 针对 prompt injection(藏在网页/邮件/表单里的恶意指令)加固了防线:升级了模型训练与探针,并新增一批分类器,让 Claude 能安全地承担更多自主操作。

**Claude Blog:Claude 在 Cowork 里拥有了自己的浏览器**

Claude 桌面版 Cowork 内置了浏览器:任务需要上网时,侧边栏会打开一个浏览器,由 Claude 自己导航、阅读、点击、输入。关键设计:这是「Claude 的浏览器,不是你的」——它与你的浏览器完全隔离,看不到你的标签页、书签和密码;需要登录的站点可以逐个站点带过去登录态(macOS 支持从 Chrome/Edge/Firefox 导入,Windows/Linux 支持 Firefox)。银行、邮箱、SSO 站点默认排除,除非你主动选择。本周起向 Pro/Max/Team 计划的桌面版用户滚动开放,企业管理员即日起可开启。

## 播客

**No Priors** — Arm CEO Rene Haas:重新定义芯片架构

Arm CEO(兼软银集团国际负责人)Rene Haas 谈芯片行业。The Takeaway:AI 没有让 CPU 变得多余,反而让它重回舞台中心——所有 token 的编排、仲裁与分发都要靠 CPU,而 Arm 正处在「所有道路的交汇点」。

核心要点:
- Arm 为何下场做实体芯片:从卖 IP 组件 → compute subsystem(乐高式蓝图)→ 去年 3 月发布首款实体 CPU「Arm AGI CPU」,起因是 Meta 想要一颗通用 agentic CPU 却没人供应。他事先跟几乎所有客户打过招呼,推阻力比想象中小得多——Nvidia、Amazon、Microsoft、Google 全员支持,发布时 Jensen 等人亲自站台。
- AI 如何重塑芯片设计:芯片设计 24-36 个月周期里,架构与 RTL 生成只占小头,**大头是验证、调试、文档——而 AI 恰好擅长这个**。Arm 内部 80-90% 的工程师每天用 AI,「关掉它就像回到 90 年代,只允许每天 2-4 点用互联网」。但 RTL 生成与物理设计仍是短板,因为公开训练数据不足——他判断 5 年以上才可能「从想法直接到 GDS2 文件」。
- 供应链是未来 3-5 年的核心肌肉:晶圆、内存、先进封装之后,**下一个瓶颈是数据中心本身的建设**,叠加美国部分地区对数据中心开发的抵制。「AI 泡沫?抛开估值不谈,供给远没到过剩,需求是贪得无厌的。」
- 机器人:他认为是「人形 + 专用」两者并存;成本下降前商业模式还没跑通,最先自动化的是工厂、配送、仓储。今天人形机器人的「大脑」(Nvidia/Qualcomm 方案)几乎都跑在 Arm 上,「机器人行业将 powered by Arm」。
- 出口管制与保护主义:作为美国人,他支持美国把半导体制造拉回本土(「需要更多美国 fab,这是国家安全」),但认为中美芯片竞赛是「无限游戏」,不会有赢家;技术领先本身没有 downside,「做落后者的代价是整部剧本都被人写好」。

「没有哪种计算问题是不用微处理器的,它是万物的心脏。所有道路都通向它、绕过它、经过它——总得有个东西来做编排、仲裁,决定 token 往哪走。这就是 CPU 的活。」
