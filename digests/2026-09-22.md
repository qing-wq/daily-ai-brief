## 播客

**No Priors — Coinbase's Everything Exchange: Agentic Finance, Stablecoins, and Tokenization with CEO Brian Armstrong**

嘉宾是 Coinbase 联合创始人兼 CEO Brian Armstrong，同时也是 longevity 公司 New Limit 的联合创始人。他把 Coinbase 的方向归纳为三块：Everything Exchange（股票、大宗商品、crypto、衍生品、perps 乃至预测市场全部上链、一个 venue 里交易），stablecoin 支付（1 秒内、不到 1 美分全球到账，即使熊市也在疯长，全球公司都在接），以及 Agentic Finance（AIFi）——普通人人手一个 AI 投顾做组合、定投、tax loss harvesting 和 yield，而 AI agent 自己也要有银行账户。他的核心论据是费用结构：信用卡单笔 30 美分保底手续费，而 Coinbase 观测到的 agent 电商交易里约 76% 都在 30 美分以下，不用 crypto rails 根本结不了账；为此 Coinbase 孵化了 X402 支付协议并捐给 Linux Foundation，Google、Cloudflare、AWS 都在跟进，还做了 edgentic.market 实时看 agentic 支付流。对内 Coinbase 在推"recursive self improvement"：每个团队、每个 repo 都有一份 brain（incident 史、风控规则、AB 测试、PR 接受/拒绝史全在 markdown 里），agent 改代码先 ingest brain，人类 review 时的修正必须写回 brain，一次修好、永久生效，one-shot PR 接受率随之越爬越高，他自己的内部 harness Toshi 甚至能调外部 vendor 并用 X402 付款——CEO 在播客开录两分钟前刚让 10 个 agent 并行干完了一个 feature 的 phase one。Tokenization 方面，已上线真实现货锚定的 tokenized stocks（非合成、非衍生，由托管的真实证券 1:1 背书，美国境外先行），目标是 40 亿没有券商账户的人；预测市场在 Coinbase App 内上线数月即达 1 亿美元收入 run rate，季度环比翻倍，Armstrong 认为体育只是娱乐表层，真正的想象力在政策实验（"这项政策一年后失业率是多少"）乃至人生大哉问的 opinion markets。New Limit 则用 AI 在巨大搜索空间里找转录因子组合做 epigenetic reprogramming，已在 humanized mouse 模型上成功 rejuvenate 至少一种人类细胞类型，正推进非人灵长类实验，明年启动针对酒精性肝病（ALD，单药潜在市场约 200 亿美元）的 phase one 临床，远期目标是肝、血管、免疫、皮肤、大脑等细胞类型的"回春鸡尾酒"——不逐个治病，直攻衰老这个 meta 问题。

The Takeaway：agent 经济需要自己的金融 rails——当 76% 的 agent 交易都在信用卡手续费之下时，stablecoin + 自托管钱包不是可选项，而是 agent 能拥有账户、能花钱办事的前提。

原文引用："We don't want the AIs to be unbanked. If we want to bank the AIs, they deserve financial services as well."
