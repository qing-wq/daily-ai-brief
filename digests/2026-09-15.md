## 播客

**No Priors — Redefining Chip Architecture with Arm CEO Rene Haas**

https://www.youtube.com/@NoPriorsPodcast

一句话：CPU 是 token 工厂的卡车车队——加速器只管印 token，运到用户手里全靠 CPU，而验证调试才是芯片 24-36 个月周期里最吃时间的部分，AI 最擅长的恰恰是这个。

Arm CEO Rene Haas 谈了几个关键点：Arm 主业是 IP 授权（手机、数据中心、汽车的 CPU 核），客户自己造（三星）或找 TSMC tape-out，覆盖面广所以对供应链全视角；去年 3 月推出第一款自研产品 GI CPU，起因是 Meta 想要一颗通用 agentic CPU、市面没人能给，于是联手做了，从 IP 组件 → compute subsystems（Lego 式拼好，省 time-to-market）→ 物理产品的自然进化，Nvidia/Amazon/Microsoft/Google 这些自研 Arm 服务器芯片的客户全都 on board，因为市面软件越多生态越大。验证调试占芯片周期大头，AI 关掉等于回到 90 年代限时上网，「genie's out of the bottle」。ChatGPT 爆发后全盯加速器，但「no computing problem doesn't utilize the microprocessor」，训练转向推理、token 越印越多，谁来 orchestrate、arbitrate、运走？That's what CPUs do。系统还是 CPU + 加速器 + 内存的 Von Neumann 结构，数据中心、汽车、机器人、手机、可穿戴通用；越小越边越是 Arm 甜点——头上戴不起 50W GPU，本地 AI 只能靠指令集和架构吃下来。
