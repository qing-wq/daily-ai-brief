**Boris Cherny** — Anthropic Claude Code 负责人

Anthropic Claude Code 核心成员 Boris Cherny 分享了 Opus 5.5 的多项重度实测。首先，他使用 Opus 5.5 配合 Lean 对 Claude Agent SDK 进行了形式化验证（Formal Verification），仅通过几条简短 Prompt 就顺畅发现并提交了 16 个修复各类 Bug 与并发竞态条件（Race Conditions）的 PR。他指出 TLA+ 同样好用，自己常将 Lean 和 TLA+ 结合用于排查数据流、并发与状态管理缺陷；虽然人类不一定精通这两门形式化语言，但 Claude 表现极其出色，能帮人类揪出极难发现的隐蔽 Bug，并抛出思考：形式化验证是否正是未来编程（或至少 Bug 排查）的终局形态？其次，团队让 Opus 5.5 与 Fable 5.1 分别将 HAProxy 从 C 语言完整移植到 Rust，两者均近乎全票通过了 HAProxy 严苛的完整测试套件，但 Opus 5.5 仅耗时 9.5 小时（Fable 5.1 为 12 小时），综合推理成本更是直降 51%。此外，他还晒出了由 Opus 制作的信息流图表。

Box CEO Aaron Levie 直呼这是 AI 领域令人疯狂的一天：前沿模型正在以前所未有的速度断崖式降价，Opus 5.5 大幅调价的同时，GPT-6 Sol 与 Luna 将 Token 价格再次暴砍 50%。历史上从未有任何技术形态能在相同任务下让单位成本如此急剧下跌，而在杰文斯悖论（Jevons Paradox）的作用下，每一次算力降价都会指数级激活智能体（Agent）的部署场景，推动智能在整个实体经济中超速扩散——从全量企业数据清洗、全代码库安全审计、海量日志自主巡检决策，到复杂的工作流 Agent Swarms。同时他公布了 Box Agent 对 Opus 5.5 进行的企业级非结构化数据复杂知识工作实测数据：整体相比 Opus 5 减少 63% Token 消耗、42% 废话输出，速度快 30%，综合成本大幅下降。在金融尽调算力审计中任务准确率提升 39%（耗费 Token 锐减 82%）；云成本优化分析准确率提高 65%（Token 减少 70%）；消费品客户综合留存分析准确率提升 17%（Token 减少 78%）；临床医学诊断数据分析准确率提升 15%（且敏锐捕捉到两组样本标准差超过 100 倍的潜在偏差并自动纠偏）。Box AI Studio 很快将面向客户上线 Opus 5.5。
