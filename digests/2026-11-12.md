## 🎙️ 播客精选

### Latent Space — Designing for Agents：Resend 创始人 Zeno Rocha 谈邮件这门"脏活"
**一个不懂邮件的前端，用设计 + DX 撕开了一个十工程师打不动的老行业：435 万用户、12 万付费客户、1000 万美元 ARR，SDK 的 NPM 下载量已是 SendGrid 的两倍**

- **"天真"是最大的优势**：Zeno 是写 CSS、HTML5 的前端，没有一天基础设施或邮件经验。他看不惯注册就要填发送量、等两天人工审核、大概率被拒的流程，于是把摩擦全部搬到平台自己身上。三年后他承认现在懂了别人为什么这么做（欺诈、钓鱼、滥用太多），但依然选择"默认信任，发现异常立刻拦截再沟通"，因为绝大多数情况是技能问题，不是恶意滥用。
- **发信是一门反侦察的手艺**：给 10 万人发信，Gmail 会限流并盯着最初那批互动。所以要把最活跃的收件人排到队首、分批、错开不同邮箱服务商、自己买 IP 段、按历史声誉分池并动态调度；滥用者买新域名、用仿冒域名、一次性群发后就消失，而信誉要的是"持续、递增地发"。原则只有一条：你要做的事，正好是滥用者不会做的事。
- **一个自动生成的纯文本版本，把送达率拉了一大截**：他们从 HTML 自动生成 markdown 纯文本一起发，"垃圾过滤器可以直接读内容，不用解析 HTML"。同时坦言打开率这个指标已不可靠（Apple 隐私保护会预读邮件），只能转向点击率；而点击追踪绝不能用第三方域名改写链接，否则一个滥用客户就能把你整个域名拖进黑名单，几天到几周出不来。
- **MCP 不是死话题，是每月翻倍**：第一个 MCP 是 a16z 的 Yoko 业余写的开源本地版，Zeno 直接把仓库要过来收进组织。月调用量从 50% 环比增长变成每月翻倍，8 月已破 120 万次；工具数从 20 多个加到 80 多个。为了做远程版被迫重做整个权限模型（OAuth、RBAC、每类资源的访问控制）。他的判断标准很消费者化：官方不维护的 MCP 我就不用，为此把 Plausible 换成 PostHog；跑步数据留在 Strava，也是因为 Strava 有官方 MCP。
- **AEO 的具体打法**：每个页面加 FAQ、全站每个页面提供 .md 版本、上 llms.txt。起因是某个周日他让模型比较各家定价，模型把 Resend 算错还点评"定价不透明"，因为 agent 不会执行 JavaScript 价格计算器；他把价格表做成 markdown 版本，几天后答案就对了。他也在重新做底层：买 IP 段、发信链路从 JavaScript 换成 Go，因为现在换语言太便宜了。
- **金句**："我宁愿活在 1000 万美元 ARR、女儿天天缠着我玩的世界里，也不想活在 1 亿美元 ARR、女儿不想跟我玩的世界里。" 他讲到 YC 时一位 partner 直言他"太在乎设计了，否则会走得更快"，他难受了几天，最后决定照自己相信的做，因为那个行业里所有人的产品都很丑，设计就是差异化。

### Box CEO Aaron Levie (levie on X)
**两个判断：agent 处理企业文件将是人的 100 倍；下一跃是 agent 集群**

- Box 与 Anthropic 合作，通过 MCP 把 Box 内容的完整读写能力接进 Claude：不只是取文件进工作流，还能把修改写回 Box 并在 Claude 里直接查看，合同、演示、战略文档都能改。
- 他把 AI 产出分成三个阶段：chat 让交互变快但受限于人；agent 能独立做完整个任务，把几小时几天压成几分钟；agent 集群（swarms）以目标为导向自己找路径，生产力提升不再有内在上限。凡是价值由"能研究多少、能用工具做多少决策、能处理多少数据、能生成多少代码"决定的领域都会被重塑：游戏、编程、交易、生命科学、IT 自动化、安全、数学、动画。新的岗位是帮企业把工作这样接起来，也就是一整片 FDE 市场。
