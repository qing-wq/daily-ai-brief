**Claude Blog：Claude in Chrome is generally available**

Claude in Chrome 正式 GA，所有付费 Claude 套餐可用。核心变化是 Claude 终于可以在浏览器里自主行动，不再需要每个动作都人工批准：一个安全 classifier 会在执行前校验每个动作是否安全、是否符合用户原始请求。Claude 能看懂当前页面并直接读写文本、点链接、跨页导航、填表单，复用用户已有登录态，覆盖日常工具连不上的内部 dashboard、legacy 系统和 vendor portal。Anthropic 强调 GA 的底气来自 prompt injection 防线：训练 Claude 识别不断增长的攻击库（内部自动化攻击、外部红队、真实监控各一路），用 probe 在 tool result 进入模型前扫描网页内容，发现可疑即警告并在必要时向用户确认，再加自动批准安全 classifier 做执行前最后一道关。评测数据上，旧 Cowork  harness 里 prompt injection 对 Claude Fable 5、Opus 5、Sonnet 5 成功率为 0；更强的红队新评测里，无额外防护时攻击对 Opus 4.5 成功率 17.6%、Opus 5 为 3.8%，而配齐 probe 加安全 classifier 后 Sonnet 5、Opus 5、Mythos 5 成功率为 0，Fable 5 仅 0.3% 且均为人工确认的低危场景。企业版可在 Organization Settings 统一管理并限制可用域名，安装入口在 Chrome Web Store，暂不支持其他 Chromium 浏览器和移动端，操作本地文件仍需配合 Claude 桌面 App。

原文引用："A safety classifier validates each action before it's performed to ensure it's safe and matches your request."
