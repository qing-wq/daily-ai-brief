## 🎙️ 播客精选

### Latent Space — Scaling Linear’s GTM to $100M ARR — Cristina Cordova, COO
**一句话：Linear 的护城河已经不是「设计好看」，而是「团队能跟上变化」；更硬的信号是，Linear 里超过一半的 issue 已经不是人建的，是 agent 建的**

- **Cristina Cordova 2023 年以 COO 身份加入 Linear**，此前在 Notion 管平台与自助增长，再往前在 Stripe 待了七年半做早期合作和 GTM。她并不认为每家公司都需要 COO：「我经常劝创始人别急着招一个我这样的人」，如果说不清「什么叫好的销售」、也就判断不了招进来的人干得好不好，那先招功能型负责人更合适。
- **她入职 Linear 时只有一名销售**，客户上限大概 500 席位，主要靠 PLG 从 Vercel、Ramp 这类公司自下而上长起来，很多客户从注册到规模化的过程中没跟 Linear 的人说过一句话。她入职三周就在全员会上把公司级目标里的「进军 enterprise」划掉了，理由是「我们只有一个人」，改成先打 growth 段、去抢那些已经在用竞品的公司，直到 2025 年才重新宣布做 enterprise。
- **换工具比买新工具难得多**：「你不能只比别人好 20%、30% 就指望人家迁移，切换成本摆在那里。」Linear 的切入点来自创始人自己在 Coinbase、Airbnb、Uber 被 legacy 工具折磨过的共同体验，而这类产品必须让人先用起来才懂，所以早期靠免费版让人自己玩。
- **最关键的数字：MCP server 2025 年上线，一年半后超过 50% 的 issue 是 agent 创建的**，同期 app 内会话量也在涨。她的判断很直接：只做一个数据库加一个 MCP server、把数据交给外部 agent，长期不是好生意，「你必须把 agent 工作流做进自己的产品，而且要做得比外面接进来的工具更好，否则人就没有理由再进你的工具」。她顺带补了一刀：chat 界面不适合可视化团队的工作，也基本是单人游戏，协作还得回到 app 里。
- **Karri 那篇「issue tracking is dead」并非突然袭击**，发布后客户一半说「对啊」，另一半问「那我到底在买什么」。Linear 的回答是从 issue tracker 变成 product development system，把资源大头投给 agent 编排、agent API、与 Codex、Cursor、GitHub Copilot 的接入。她承认 2025 年原本计划的企业功能有一堆没做完，「我们选择 race ahead」。
- **反常识的团队选择：不招 SDR**。第一通电话本质上只是问「你们多大、预算多少」，客户只想看 demo。客服也拒绝「100% 由 LLM 首答、客户发火才转人工」的模式：AI 起草，人做质检。三年半里她没收到过一次因客服体验差而升级的投诉。
- **怎么收钱**：seat-based 保留，新 AI 功能走 usage-based 或 credits，按 API 成本加一点透明加价；定价策略是有意「先贵后降」，而不是先便宜再被迫涨价。
- **组织形状**：约 170 人，只有创始人和她一个 C-level，产品路线图最多排 6 个月。她从 Stripe 学到的是给工程/产品/设计设一条 40% 的 headcount 水位线，销售想加人，先去帮忙招工程师。她明确不想从 Stripe 带来的东西是「永远相信能招到更好的人」，因为那会让公司一直想从外面买更强的 leader，而不是让已经做出东西的人长大。
- **她给过去的自己一句话**：「Calm down, it’ll all be fine.」2023 年入行时正撞上创业公司大出清，现在这轮 agent 冲击同理：没人能预测未来，靠近客户、保持速度就够了。

### Box CEO Aaron Levie (levie on X)
**「别再教 agent 怎么做了，给它目标就行」：今年的能力跃迁是让模型去解你自己都定义不清的问题**

### Vercel CEO Guillermo Rauch (rauchg on X)
**「个人购物 agent」是他试 eve 时的 hello world，现在这条路能直接 ship 了；顺便给 AI 基础设施定了个新基线：ISO 42001**

- 回顾第一次跑 eve 内部预发布版：购物 agent 能跑，但基础设施全缺。现在 AgentCard 这类支付/卡产品有了，iMessage 和 WhatsApp 渠道成熟，性能大幅提升但没牺牲持久性和加密，所以可以直接用他们的 open intelligence stack 跑出一个 Muse / Instinct 级别的平台，「Run with this template. Make it your own.」
