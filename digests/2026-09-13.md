## 播客

**No Priors — Coinbase's Everything Exchange：Agentic Finance、Stablecoins、Tokenization，对话 CEO Brian Armstrong**

https://www.youtube.com/watch?v=uLDK4l_-gUE

一句话：crypto rails 正在变成 AI agent 的默认支付层，因为传统信用卡吃不下 penny 级的机器交易，而 Coinbase 想给 agent 本体开户。

Coinbase 联创兼 CEO Brian Armstrong 摆了三个并行赌注：Everything Exchange——股票、crypto、衍生品、预测市场放一个地方交易、跨品种保证金；stablecoin 支付——全球 1 秒内、1 美分以下到账；Agentic Finance——人和 agent 都有金融账户。锚定全场的数字：团队看到的 agent 电商交易里约 76% 在 30 美分以下，这个价位上 30 美分卡手续费根本没法玩。他的解法是自托管 agent 钱包 + x402 支付协议，现在已进 Linux Foundation，Google、Cloudflare、AWS 都在里面——agent 被 paywall 卡住、或要花 AWS 额度时，能从隔离额度里自己付钱。

Coinbase 内部更意外的是工程的递归自改进：每个服务都有一个「brain」——活的知识包（incident 历史、财务控制、A/B 结果、merged PR 历史），agent 改 repo 前必须先 ingest，人类的每次纠正都回流进 brain，one-shot PR 接受率越跑越高。Armstrong 说他现在用前沿模型规划功能，10 个并行 agent 甩给便宜模型（含 Grok 和开源权重），几分钟后直接 review 成品 PR，不用在 Slack 里 @ 团队了。市场上：88% 收入已来自非 BTC 交易，tokenized stocks 在美国之外以上市实物证券（托管、非合成）开卖，App 内预测市场上线几个月就干到 1 亿美金 revenue run rate。原话：「We don't want the AIs to be unbanked.」
