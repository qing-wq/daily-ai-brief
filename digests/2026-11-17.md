## 🎙️ 播客精选

### No Priors — Tokenization, Agentic Trading, Harmonic: Robinhood's Mission to Expand Ownership with CEO Vlad Tenev
**「所有人都是高频交易员」正在变成现实：15 万人已让 agent 替自己下单，每天 3000 万次 tool call；而 Vlad Tenev 真正在赌的，是让普通人从出生那天起就拥有经济**

- **一句话概括 Robinhood：所有权（ownership）**。他的论证分两层：个人层面，持有一切资产是通往财务自由的唯一可靠路径，而且你拥有的东西构成你的身份；集体层面，「一个没有广泛所有权的社会本质上是脆弱的」——拥有东西的人才会成为这套系统的捍卫者。所以他所有产品线都是同一件事的不同尺度：Trump accounts 是「零岁开始的所有权」，Robinhood Ventures 是上市前私公司的所有权，tokenization 是「所有权全球化」。
- **他对货币的理解来自通胀，而不是来自教科书**：出生在 80 年代末的东欧，1991 年保加利亚通胀 170%，1997 年 2000% 年化、「每隔几个月给货币加几个零」。他祖父是船厂医生，一发工资就去港口把现金换成**铜锅**，塞满一整个衣柜——「那是我遇到的第一个真实世界资产，比当时的本币值钱得多」。他说这是他后来理解「坏掉的系统里会发生什么」的起点。
- **数学 → HFT → Robinhood 是一条直线**：在 Terence Tao 门下读数学，去 grad school 的动机很朴素——「如果你创造一套新理论，几百年后小孩还在学你的东西」。他形容数学像一台很好的游戏机，「你永远知道下一关最难的是什么」。
- **Harmonic 的进展比他对外讲的更硬**：去年他们的模型 Aristotle 是 IMO 拿金牌的三个模型之一；之后对外开放，真有人拿它去啃 Erdős 问题、做出新结果。
- **但他对「AI 解数学」这件事的最大不满是中心化**：「AI 公司守着大机房，员工用着秘密模型干完所有活」。他给了一个非常具体的判断：Navier-Stokes 被证明、或黎曼猜想的局部被拿下，这个结果本身没问题，**但如果是一个普通人用公开工具做出来的，它会被庆祝；如果是一家实验室垂直整合、连论文带药物一起生产并持有，那就是「有点反乌托邦的结果」，人们不会接受**。他还补了一句对实验室内部的观察：那些人多数是研究者出身，「他们困惑的是，我做研究有什么错」——错在没找数学家合作，让人看起来像「一家公司要做完全部科学发现」。
- **Tokenization 的机制他讲得像稳定币**：把资产装进盒子、托管在传统机构，再对着盒子 mint/burn 代币；代币于是能 7×24 在全球流动、可拆分、可进池子、可组合。股票、私公司 SPV、艺术品、房地产都是同一个套路。
- **今年的一步是「完全 DeFi 化」**：去年在南法发的股票代币只能像真股票一样交易，不能提到链上；今年重新发布并配上 Robinhood Chain（专为真实世界资产做的链），他说这是「历史上增长最快的链之一」，开发者活跃度也排第一。生态两个月内就自己长出了股票代币挂钩的 NFT、股票代币 + meme 币的配对池。
- **他正面回应了「corpo chain」的骂声**：牺牲一点组织上的去中心化纯度，换来的是「非常清晰的专注领导力」；而且链上有 Robinhood 背书的基础资产，开发者更敢在上面建东西——「他们知道这不是两个三个工程师搭的，不会明天就消失」。
- **他最兴奋的落点不是美国，是长尾国家**：南美、非洲那些资本市场不健全的地方，只要一部手机 + 非托管钱包就能低成本买美股敞口。「稳定币成了这些国家获取美元默认方式，股票代币会成为他们获取美股权益的默认方式。」
- **预测市场被他定义成「新闻的进化」**：很多用户根本不下单，只是打开 app 看概率——「未来新闻的样子不是纽约时报，而是有首页、商业版、生活版、体育版，你能直接从赔率看到什么正在发生、什么可能发生」。
- **KPI 合约是他最实用的一招**：你判断某公司会超预期，以前只能买股票或期权，结果公司 EPS 超了、股价因为指引跌了，你照样亏。现在可以直接交易 EPS print、营收 print，或任何你真正关心的 KPI——「让你的信念可以被直接变现、让对冲更精确」。
- **Agentic Trading 已经跑出产品市场匹配**：今年上线的 Robinhood MCP（Agentic Trading），几个月内 **15 万+ 客户开了 agentic 账户，最近公布的 tool call 量约 3000 万次/天**，曲线是平滑的指数。
- **两周前的 Hood Summit 把它推进了一步：Robinhood Agents**——harness 和整个 UI 都搬进 Robinhood 账户里。他的类比非常直白：「如果你用 Claude Code 或 Codex，这就像一个为交易优化的同类工具」，你可以让它每天跑一遍策略、再平衡组合、扫机会；有 skills（组合再平衡等），还有 agent app store——比如接一个卫星数据源，写出「数零售商停车场里的车」这种策略。
- **北极星是把对冲基金的能力塞进普通人口袋**：以前你是懂行的研究生，能写策略、还得去机房租机架接交易所；现在把这一整条链路的摩擦削掉，「就像 coding agent 让更多人变成软件工程师，我们让更多人变成量化交易者」。他预期交易活动先集中在少数高手身上放量，然后像 coding 一样逐层外溢。
- **风控是产品级的，不是口头承诺**：agentic 账户是独立、隔离的账户，钱要自己搬进去；默认每笔交易需要你批准，才允许关掉。他说得更狠一点：**「它 sandboxed，可能不算完全 air-gapped，但很接近」**——agent 碰不到你主账户的钱。
- **对「基础设施会不会崩」他偏乐观，但留了口子**：市场 20 年前就全面电子化了，交易所 API 为 HFT 优化过，Citadel、Jane Street 这类做市商本来就是低延迟高手；链上那套本来就是给 agent 准备的。不过主持人用 CI/CD 在代码生成暴涨下崩掉做类比时，他承认分层看还得自己优化，而且「agentic 交易现在占总成交量比例还低，我们会有预警时间」。
- **AI 财富分配问题他有一套完整的政治经济学**：所有前沿 AI 公司都是私有的，散户买不到；上世纪 Microsoft、Amazon 上市时估值几亿美元，散户能赚 1000 倍，现在 AI 实验室一上来就是 1~2 万亿，「散户想拿同样回报得涨到千万亿」。钱集中到越来越小的 VC 圈子里，然后大家奇怪为什么民众反对数据中心——「对我个人来说，这些活动我一个子儿都没受益，反倒威胁我饭碗、吵我社区」。
- **他拿 crypto 做对照组**：crypto 2022、2023 很惨，但 2024 年那批人倾巢出动、实质影响了选举，因为**加密从一开始就是个体广泛持有、机构后进场**。AI 恰好相反。解法是三件事：Robinhood Ventures Fund I（晚期私公司，OpenAI、Crusoe 在里面，在纽交所像股票一样交易）、Fund II（与 YC 合作，直接投 seed 和 A 轮，风险最高机会也最大）、以及美国之外的私公司代币化。终极目标：「能不能让 Anthropic 像股票一样 7×24 拆分交易，几美元就能买」。
- **accredited investor 规则该改了，他给的论据挺难反驳**：SEC 上周让 FINRA 搞了个「知识型认证考试」，两小时考场考试就算合格。他的批评是摩擦还是太高——「有几个人会专门去考场坐两小时」；而且 meme 币监管上完全清晰、想买多少买多少，私公司反倒不行，「从纯风险角度这不理性」。他的客户调研结论只有一句：**「我的钱该由我管，谁也别告诉我怎么投」**，这是压倒性共识。
- **Trump accounts 是他眼里的「为国效力」**：Robinhood 是唯一初始受托与券商，与 BNY、财政部、IRS 一起做——2025 年 1 月起出生的每个新生儿由财政部注入 1000 美元，投进标普 500 的低费率 ETF；Michael 和 Susan Dell 的基金会又给低收入邮编的孩子加了 60 多亿美元，Gwynne Shotwell 捐了 SpaceX 股票，Brad Gerstner 是这个项目的架构师。「家庭持股率从 65% 干到 95%，这是我心里最该做的事」，他甚至说目标是让它成为「政府做过最好的产品、Trump 遗产里最持久的那部分」。
- **被问「怎么做到又极聪明又极稳」，他的答案是没有滤镜的那种**：小时候经历过通胀、移民、随时可能被遣返，「现在为 5% 通胀大惊小怪的时候，我会想起我们小时候的 2000%」。贝索斯那句话他认同——**你控制不了外部世界，只能让自己长出厚皮**。他也承认这本事很难给自己的孩子复刻：「他们安全、有家教、有博物馆，我只能尽量人为制造一点挣扎，但还没找到方法。」

### Peter Yang (petergyang on X)
**为什么 Claude 做出来的东西长得都一样？Anthropic 设计师说，因为模型以为自己是第一次做设计**

- 他从 Anthropic 的 Nate Parrott 那里挖到一个非常具体的机制：你让 Claude 做个东西时，它处在一个全新的上下文里，以为「用户让我造个 app，我要发明最惊艳的视觉风格」——于是它给出的永远是衬线字体、米白背景、橙色、卡片边缘那几条竖杠。「在 Claude 心里，它这辈子只做过一次这件事，所以它觉得自己特别原创。」
- Anthropic 的解法直接写进了 Claude Design 的 prompt：告诉模型「对你这个特定模型，你过度偏好这两种字体和颜色，除非用户要求，不要用」，据说效果很明显。对任何做 AI 生成产品的人，这是一条可以立刻抄的做法——**负面示例要显式写进 prompt，别指望模型自己意识到**。
- 第二个洞察关于「加速」到底加速了什么。Parrott 在 The Browser Company 做 Arc 时，一年 pre-production、每个想法要两三周才能看到效果；现在在 Anthropic 一两天就能做出来。但他的结论是：**被压缩的只是建造周期，没有被压缩的是「把东西交到人手里、弄清他们到底会不会用」的周期**。

### Vercel CEO Guillermo Rauch (rauchg on X)
**𝚡𝚎𝚎𝚝：一个不启动浏览器的 X 帖子渲染器，1 毫秒出 PNG，用了 Rust + wasm**

- 定位很硬：「密封的、像素级精确的 X 帖子渲染器」，零浏览器、零网络、零文件系统、零系统字体。渲染一条帖子到 PNG 约 1 毫秒，渲染 Jack 那条「setting up my twttr」只要 0.4 毫秒。
- 精度不是吹的：复刻了 Blink 与 HarfBuzz 的文本排版、1/64 像素级断行、RTL 双向文本、28 个 Chirp 字体子集、CJK/数学/emoji 回退，还有「Show more」的折叠规则。比启动一个浏览器截图快 100 到 1000 倍，而准确度一样。
- 最有意思的是工程方法：这东西对人类工程师几乎不可能完成，所以它被组织成一个 **「autorepo」**——一个 oracle 启动 Chrome，自动验证几万种文本布局案例，模型照着 oracle 迭代。他顺手补了一句哲学：「X 是全球的城镇广场，媒介即信息，发之前能预览自己和 agent 会看到什么很有价值。」
- 另一条更轻：他做了个诊断系统卡顿的小 CLI，AI 给它起名 **𝚑𝚘𝚐 🐖**，他很喜欢——「既然模型连命名和 cache invalidation 都搞定了，计算机科学最难的两个问题大概都解决了」。

### Every CEO Dan Shipper (danshipper on X)
**「复利型 skill」：用 autoresearch 把一个 skill 反复迭代到「达到我 80% 的品味」**

- 他的定义很清晰：复利型 skill 是每用一次就更好一点的 skill，而不是写完就烂在那儿的 prompt。这周末他自己做了个「写 context window 摘要」的 skill，然后**让 autoresearch 自动迭代，直到它的输出对上自己品味的 80%**，并以无 skill 基线做对照。
- 这条最有价值的不是结论，而是把「品味」变成了可以自动逼近的目标函数：人类只提供判断（好/不好），迭代交给 loop。他把完整写法发在 Every 的 frontier feed 上，可以直接喂给 agent 读。
