### AI & I by Every
**Factorial Capital 管理合伙人 Matt Hartman：《Hugging Face 早期投资人如何辨识 AI 时代的赢家》**
- **核心结论（The Takeaway）**：在任何人都能靠“Vibe Coding”（氛围式提示词编程）瞬间拼凑出软件原型的时代，真正的竞争壁垒不在于你能跑多快做出 Demo，而在于面对技术涌现时你所提问题的深度，以及承担长期软件维护（Maintenance）与打磨非显性细节的耐力。
- **对话背景**：Matt Hartman 是 Factorial Capital 管理合伙人，早年在 BetaWorks 期间主导了对 Hugging Face 的天使轮投资。他拥有工程背景并在大学期间就曾手写神经网络，多年来专注于投资因技术底层突破而“最新变为可能（newly technically possible）”的前沿赛道。
- **反共识与前沿洞察**：
  1. *Hugging Face 早期做对的“恒量法则”*：Hugging Face 最早始于一款面向年轻人的聊天机器人。当 Transformer 论文发布后，团队迅速将其移植至 PyTorch 并开源，意外在 GitHub 引爆。Hugging Face 做对的一千个决定中，最关键的是**始终将开源作为唯一不变的恒量**，而对其上承载的模型形态（语言、视频、生物、气象、具身智能）保持最大维度的敏捷与弹性。
  2. *“SaaS 末日论”的误区与维护成本法则*：当下行业流行宣称“SaaS 已死”，认为人人都可为自己 vibe code 出专属软件。但 Hartman 在自己手搓本地语音转文字软件（获得 3000 多 GitHub Star）后深刻体会到：**自己写软件最昂贵的不是构建，而是长期的维护成本**。商业 SaaS 软件收取的订阅费，本质上是在买断团队持续保障系统稳定、接口兼容和底层调优所消耗的时间与精力。
  3. *AI 时代提问的杠杆*：当编写代码的边际成本趋于零，技术理解依然至关重要，但它改变了发挥作用的形式——它决定了你能否问出直击底层本质的关键问题。
  4. *金句铭刻*：“最优质的商业构想，永远来自于你在最前沿技术中亲自玩耍、折腾和碰撞（tinkering），并真实感知那些尚未被解决的粗糙痛点之中。”
