### Unsupervised Learning — Ep 97: Jev Creator on Decision Models, Benchmark Fatigue & Why the Labs Missed It
**「模型的形状」一周就能做出来，真正难的是可靠性——而整个行业正在用刷榜提前烧光开发者的信任**

- **起点是一个比例问题**：把 LLM 当成被软件调用的一个 API 子模块，然后问：这些调用里有多少是给人看的、多少是给机器看的？他说哪怕最「string-pilled」的人也会承认，机器原生那一侧要吃掉好几个九，分歧只在什么时候发生。「那就从这个认知内核倒推，把它做出来。」这也是公司叫 Jev 的原因——Jevons 悖论：他们确实看到了需求随价格下降而反弹，但还没看到 backfire（总市场变大），因为前提是「好到又便宜、到处都能创造价值」。
- **他坚持叫它「系统一模型」**：AI 最终被压缩成的形状本来就很系统一，所以把短板如实讲出来才是诚实的做法，「对软件来说这本身就极其有价值」。他反问一句：我们能解千禧年数学奖级别的难题，却自动化不了任何碰会计的事——这件事本该让所有人觉得奇怪。
- **行业还坐在「瓦力」的椅子上**：真实世界的使用反馈几乎没进他们的路线图，「大家应该多来骂我们」。他抱怨开发者已经习惯了「模型厂商按自己那条路走、我们被动接受」，而「计划着 AI 会改变，却没有把这件事带向哪里的能动性，这既让人无力，也挺没劲的」。内部玩笑是：想让他本人回消息，最好的办法是聊模型锯齿（jaggedness）；想聊合作、想合影，去找 CTO。
- **他担心的不是形状不够多，而是没人管可靠性**：做形状他以为要一周，结果就是一周；现在一堆人在做类似形状的模型，但「形状跟它有没有用比起来根本不重要」。他直接把这类发布叫「overpromise, underdeliver」，说这会烧掉开发者的善意，最惨的是那些没时间自己测、只能被卷进去的开发者。
- **反 benchmark 的立场很硬**：要判断「超人类」，就看最优秀的公司到今天还得人在环里——「如果他们真的那么擅长软件，普通软件工程师为什么还有活干？」而榜单饱和得比他预期快得多：人们已经被骗太多次，现在根本不在乎新模型发布，「这对我们公司是好事，对整个领域是坏事」。
- **KV cache 是编码 agent 的隐形枷锁**：几乎每一个真正改变功能的 UX 决策都围着 KV cache 转，因为它只能 append。「你的状态就像全局变量，一个巨大的字典一路传下去，直到模型开始变笨」——context rot 是真实存在的。代价是路由做不动、子 agent 不知道该传哪些上下文、compaction 变成没有先验的压缩。
- **他真正想做的几个「科幻」功能**：多个 agent 读写同一份上下文；用更便宜的模型实时把 Opus 正在做的事画成可视化，而不是让人去读满屏乱码进度；按「你在解什么问题」做语义压缩、用代码算 cache 读写的 ROI 再决定重建哪份 KV cache；对全部历史做一次极便宜的 MapReduce 把系统抽象捞回来，还能和同事共享。
- **Jev 的终局应该像 SQL**：可靠到 provider agnostic，而不是逼开发者去揣摩每个子模型的「心智理论」，把系统锁死在某一家身上。
- **多模态会掉智商，而且可测**：每个模态的掉幅不同，只是进了聊天框就被人类偏好指标糊掉了。所以他的原则是「先自动化容易的活，再谈难的活」——要拿这类模型去自动化软件工程之前，该先认真研究 LLM 为什么连简单任务都失败，而且不是绕过它，是钻进去。
- **图像模型只有文本的 10%**：他的原话是「要我说它 prod ready 我会觉得丢脸」，还没拿到他的盖章。图像侧他偏爱两个方向：游戏（他有游戏背景，还玩过自动打怪，「软件有点像把技术掰成你想要的形状」）和 computer use（「AI 在界面这件事上这么差，其实挺让我困惑的」）。
- **「我们本可以一年前就有 AGI」**：他在 OpenAI 写过一份同名文档，理由是 GPT-3.5 甚至 GPT-3 时代的模型在大量维度上已超过中位人类智力，按 OpenAI 的 AGI 定义（承担世界上大部分有经济价值的工作）本该早就能用起来。GPQA 在 2023 年前后就到了博士生水平，「那种级别的智能没被投入使用，这才是悲剧」。
- **编码 agent 提速 20%～40%**：这是他的估计，且误差很大——取决于场景和用户水平，有的场景是「无限倍」（以前根本做不到的事），有的场景跟手写一样慢；长期还要扣掉技能退化和技术债。
- **对 Anthropic 上市泼冷水**：他承认 coding agent 极其值钱，但「它值钱」和「值这个估值」是两件事，有多少用量是真的净正向得由产品团队自己回答。更狠的一句是：实验室最强的能力不是模型、产品、分发，而是金融工程，尤其在算力合约上；「泡沫可以只因为预期没兑现就破，而不需要这项技术不具变革性」。至于「让他们去治癌症」这句话，他说会变成玛丽·安托瓦内特的「让他们吃蛋糕」。
- **AI 安全不是一块铁板**：ASI、生物风险、网络风险、信任与安全是四件不同的事。他判断真正的 agency 还差「两次量级巨大的突破」，一次都不够；批评 RSI 论者既不了解 AI 史、也不看 Amdahl 定律；把 Bostrom 的《超级智能》当现实而不是当一本有趣的科幻来读，让他担心。
- **收尾是一句行动号召**：别再习惯 LLM 教给我们的那种「没有能动性」的状态，「回到玩的状态，而不是当受害者」。

### Box CEO Aaron Levie (levie on X)
**「越来越多的工作会变成 coding-shaped」——不是模型什么都得懂，而是它得会用软件，再叠加领域判断**

- 推理链是这样的：模型在编码、工具使用、computer use、数学上进步最快，所以能写代码或操作软件的 agent，会比其它知识工作领域跑得更快。结果不一定是「只有一小部分工作能被自动化」，更可能是大量工作被改造成 agent 擅长的形状。
- 他明确修正了行业的老心智模型——「模型必须无所不知才能创造价值」：真正需要的是「高效地使用或生成软件」，再叠加深厚的领域专业判断，两者结合才解锁其它一切。
- 最近的模型发布就是证据：agent 生成的代码能变成动画视频、游戏、产品的 3D 模型。结论是知识工作里 agent 的加速只会越来越快。
