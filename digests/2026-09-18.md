## 官方博客

**Claude Blog — Claude Cowork and chat are now one Claude**

https://claude.com/blog/cowork-is-now-claude

今天起 Claude Cowork 和 chat 合并成一个 Claude：丢个快问过来，或者把中午到期的报告甩给它，哪怕你合上笔记本它也接着干，先上 Pro 和 Max，未来几周 rollout，Team、Free 和 Enterprise 随后。一起发布的是 Claude Docs 和 Claude Slides，加上对话内可用的 Claude Design——要文档就和 Claude 一起写，要 deck 就让它起草，直接改、直接 present、下载 PowerPoint 或 PDF，三者都在 paid plan 上 beta，Enterprise 由管理员决定何时开。为什么合并？之前 Cowork 管大活、Design 管视觉活，用户最烦的是决定任务该放哪，在一边开的头到另一边接不上。现在不用选了，Claude 自己判断任务要什么，Cowork 和 Design 的能力在任何对话里都可用，context、skills、connectors 全跟着走。官方举例：周报中午到期，出门前问一句上周 pipeline 动了什么，再补一句「按老样子写，掉队的标出来，highlights 做五页给 leadership 会」，含糊处 Claude 会追问，路上手机上看进度，到工位报告 doc 和 slides 都在同一个对话里等你，slides 天然和报告对得上，还能设成每周一自动开工。Senior Economist Andrew Keller 的证言很形象："I could have Claude pull up [my legal research database], and it would pull all the cases, read them, figure out which other cases I might need, download them, and store them in a folder for my personal review." Cowork 老用户什么都不用动，打开 app 接着干；纯 chat 用户也不用学新东西，下个报告或 deck 直接甩给它就行，手头有 messy 大项目的话现在就是时候。
