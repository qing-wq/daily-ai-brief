## 官方博客

**Anthropic Engineering — How we contain Claude across products（我们如何在全线产品中对 Claude 施加安全沙箱与遏制）**

https://www.anthropic.com/engineering/how-we-contain-claude

**核心要点**：
- **安全与权限评估的代际转变**：一年前，Anthropic 内部绝不可能考虑赋予 Claude 足以让内部系统下线的关键权限；而今天这种级别的权限已成为日常，且极大提升了工程团队的生产力。
- **爆炸半径（Blast Radius）工程化控制**：智能体部署风险由“故障发生概率”与“潜在破坏力（理论爆炸半径）”构成。虽然模型安全对齐极大降低了误操作率，但随着能力拓展，潜在破坏范围也在扩张。当智能体能够完成过去需要整个团队才能胜任的工作时，不采用智能体的机会成本将巨大到迫使天平向全面落地倾斜。工程的核心问题在于**严格限定爆炸半径**（如沙箱环境隔离、细粒度凭证管控与即时风控）。

**Anthropic Engineering — An update on recent Claude Code quality reports（近期 Claude Code 体验波动的技术复盘与根因分析）**

https://www.anthropic.com/engineering/april-23-postmortem

**核心要点**：
- **透明复盘三大并存 Bug**：针对部分用户反馈的回复水准下滑，团队澄清 API 与推理底层未受任何影响，问题根源出在针对客户端的 3 项改动：① **默认推理强度（Reasoning Effort）从 High 误下调至 Medium**（为降低延迟却牺牲了智能，现已根据社区强烈反馈改回默认 High）；② **会话空闲思维清理 Bug**（本意是优化闲置 1 小时后的恢复延迟，却意外导致后续每个轮次都被清空思维链，使得 Claude 显得健忘重复）；③ Agent SDK 与 Cowork 相关配置冲突。目前所有问题已全面修复。

**Anthropic Engineering — Scaling Managed Agents: Decoupling the brain from the hands（托管智能体扩展之道：让思考大脑与执行双脚彻底解耦）**

https://www.anthropic.com/engineering/managed-agents

**核心要点**：
- **拒绝为过去写死代码，拥抱长效抽象**：过去的智能体 Harness（外挂框架）往往预设了模型在特定上下文中的局限（例如曾为 Sonnet 4.5 专门打补丁解决“上下文焦虑/提前交卷”，但在 Opus 4.5 上该限制早已天然消失，框架补丁反成累赘）。
- **向操作系统看齐的设计哲学**：借鉴数十年前现代 OS 将硬件抽象为通用的 Process 和 File 的智慧，Anthropic 构建了 Managed Agents 平台，打造能够超越任何特定版本模型寿命的接口，让开发者专注于长程业务逻辑调度，免除维护底层基础设施与守护进程的繁琐负担。

## 播客

**No Priors — Beam: The Great American Open Model with ReflectionAI Co-Founder and CEO Misha Laskin**

https://www.youtube.com/@NoPriorsPodcast

The Takeaway: 开源开放权重（Open-weight）模型不仅是技术民主化的基石，更是国家级网络安全与关键基础设施防御的终极解法；面对长尾风险，唯有遵循“林纳斯定律（Linus's Law）”，汇聚全社会的众包监督才能将安全隐患降到最低。

Reflection AI 联合创始人兼 CEO Misha Laskin（前 Google DeepMind 研究员、物理学博士）做客 No Priors 播客，深度分享了打造前沿开放智能系统 Beam 的心路历程与深层思考：

1. **防御网络攻击依赖开放模型的力量**：当你剥夺了模型的网络攻击能力时，往往也同时剥夺了它的网络防御与渗透排查能力。现实世界中，仅靠封闭实验室内部百余名安全研究员，根本不可能穷尽所有长尾风险与意外后果。事实上，当一家企业遭遇未知封闭模型的恶意渗透时，往往只有借助透明可控的开放模型才能完成即时排查与自我修复。
2. **安全领域的林纳斯定律**：“在足够多的注视下，所有的 Bug 都会浮出水面”。将前沿模型开放给全球开发者与安全团队，不仅不会摧毁安全，反而是消除潜在系统性软肋与安全盲区最坚实的保障。
3. **前沿开放智能的冲刺竞赛**：在过去 12 个月里，团队从 30 人迅速扩张，如同在飞行途中拼装飞机。Reflection AI 致力于在算力与数据层面打造对标全球顶尖水准的前沿开放智能，为开发者提供真正主权可控的智力底座。
